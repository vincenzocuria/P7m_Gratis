Domande Frequenti (FAQ)

Generale

Cosa sono i file .p7m?

I file con estensione .p7m sono documenti firmati digitalmente utilizzando lo standard CAdES (CMS Advanced Electronic Signatures) basato su PKCS#7. Vengono utilizzati principalmente dalla Pubblica Amministrazione italiana e dalle aziende per garantire autenticità e integrità di documenti ufficiali come fatture elettroniche, determine, contratti e comunicazioni PEC.

Come faccio ad aprire un file .p7m?

Puoi aprire un file .p7m in due modi:

  • Online: Carica il file su questa pagina. Il documento viene estratto e puoi scaricarlo.
  • Desktop/Mobile: Scarica l'app gratuita P7M Viewer per Windows, Android o iPhone.
Questo servizio è gratuito?

Sì, completamente gratuito per l'uso singolo e per batch fino a 20 file.

Privacy e Sicurezza

I miei file vengono salvati sul server?

No, mai. Tutti i file vengono elaborati in memoria (RAM) e cancellati immediatamente dopo l'invio della risposta al tuo browser. Non conserviamo alcun dato, né file né contenuti estratti. Leggi la nostra informativa sulla privacy.

È sicuro caricare documenti riservati?

Il servizio è progettato con la massima attenzione alla privacy:

  • Connessione HTTPS crittografata
  • Nessuna conservazione dei file
  • Server in UE
  • Codice del decoder pubblico su GitHub

Se preferisci elaborare tutto offline, usa l'app desktop P7M Viewer.

La firma digitale viene verificata?

Sì. Il servizio verifica:

  • Integrità crittografica della firma CMS
  • Corrispondenza del digest del contenuto
  • Validità del certificato del firmatario
  • Catena di fiducia (se i certificati intermedi sono presenti)

La verifica di revoca OCSP/CRL viene tentata dove possibile. Come per tutti i viewer, questa verifica è informativa e non costituisce una validazione legale completa eIDAS.

Fatture Elettroniche

Posso convertire fatture elettroniche .xml.p7m in PDF?

Sì! Il servizio riconosce automaticamente le fatture elettroniche FatturaPA e genera un PDF leggibile con tutti i dati principali: cedente, cessionario, dettaglio righe, riepilogo IVA e totali.

Posso convertire più fatture in un colpo solo?

Sì. Carica un file ZIP contenente fino a 20 fatture .xml.p7m. Il sistema elaborerà tutte le fatture e ti fornirà un riepilogo Excel con fornitore, numero, data, importi e IVA di ciascuna fattura.

Se hai scaricato lo ZIP "Fatture e Corrispettivi" dall'Agenzia delle Entrate, puoi caricarlo direttamente.

Il PDF generato ha valore fiscale?

No. Il PDF è una "copia di cortesia" per facilitare la lettura. L'originale con valore fiscale è sempre il file XML trasmesso al Sistema di Interscambio (SdI).

Posso ottenere un Excel delle fatture?

Sì, per batch di fatture (ZIP). L'Excel generato contiene:

  • Foglio "Riepilogo Fatture": fornitore, P.IVA, numero, data, imponibile, IVA, totale
  • Foglio "Riepilogo IVA": totali per aliquota IVA

Limiti e Batch

Ci sono limiti di dimensione?

Sì, per prevenire abusi:

  • File singolo: massimo 10 MB
  • ZIP: massimo 50 MB totali
  • Numero file in ZIP: massimo 20 file (versione gratuita)
Posso elaborare più di 20 file?

Per la versione gratuita online il limite è 20 file per caricamento. Se hai bisogno di elaborare batch più grandi, ti consigliamo di usare l'app desktop P7M Viewer, che non ha limiti di numero file.

C'è un limite di caricamenti al giorno?

Sì, per prevenire abusi applichiamo un rate limit: circa 20 caricamenti per ora dallo stesso indirizzo IP. Se superi il limite, attendi qualche minuto e riprova.

Tipi di File Supportati

Quali tipi di file .p7m sono supportati?

Il servizio supporta:

  • Buste CAdES (file .p7m, .p7s, .p7c)
  • Buste annidate (es. file.xml.p7m.p7m)
  • Fatture elettroniche .xml.p7m
  • PDF firmati (PAdES)
  • Firme detached (.p7s)
  • Contenitori ASiC-S e ASiC-E
  • Firme XML (XAdES, XML-DSig)
Funziona con i file scaricati dall'Agenzia delle Entrate?

Sì. Puoi caricare direttamente lo ZIP scaricato dalla sezione "Fatture e Corrispettivi" o "Download Massivo" del portale dell'Agenzia delle Entrate. Il servizio elaborerà tutte le fatture contenute.

Problemi Comuni

Il file .p7m non si apre / errore durante l'elaborazione

Possibili cause:

  • Il file è corrotto o incompleto
  • Non è un vero file P7M (alcuni file hanno solo l'estensione .p7m ma non contengono una firma valida)
  • È una firma detached (.p7s) e serve il file originale separato

Se il problema persiste, prova con l'app desktop o contattaci.

La firma risulta "non verificata" o "revocata"

Può succedere per diversi motivi:

  • Il certificato del firmatario è scaduto
  • Il certificato è stato revocato
  • Il server OCSP/CRL non è raggiungibile
  • Mancano i certificati intermedi nella catena

La verifica è informativa. Se hai dubbi sulla validità legale di una firma, consulta un esperto.
