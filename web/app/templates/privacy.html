3. Quali dati raccogliamo e perché

File caricati

Cosa succede: Quando carichi un file .p7m o ZIP, viene:

  • Letto in memoria (RAM) del server
  • Elaborato per estrarre il contenuto e verificare la firma
  • Mai scritto su disco - il file originale caricato non viene mai salvato

I file originali caricati non vengono mai salvati, né su disco né in memoria oltre il tempo di elaborazione.

File generati (PDF, Excel)

Cosa succede: I risultati dell'elaborazione (PDF delle fatture, file Excel riepilogativo):

  • Vengono mantenuti solo in memoria (RAM), mai scritti su disco
  • Restano disponibili per il download per massimo 10 minuti
  • Vengono cancellati immediatamente dopo il primo download riuscito
  • Vengono automaticamente cancellati dopo 10 minuti anche se non scaricati

Perché questa scelta: Per permetterti di scaricare i risultati, dobbiamo mantenerli temporaneamente. Abbiamo scelto il periodo più breve tecnicamente ragionevole (10 minuti) e la cancellazione immediata dopo il primo download per garantire la massima privacy.

Dati di navigazione (log tecnici)

Il server registra solo:

  • Indirizzo IP (per rate limiting anti-abuso)
  • Data e ora della richiesta
  • Dimensione del file caricato
  • Esito dell'elaborazione (successo/errore)

Non registriamo: nomi dei file, contenuto, dati estratti dalle fatture, né altri dati personali.

Base giuridica: Legittimo interesse (art. 6.1.f GDPR) per garantire sicurezza, prevenire abusi e mantenere il servizio operativo.

Conservazione: I log tecnici vengono conservati per massimo 7 giorni, poi cancellati automaticamente. I file generati (PDF, Excel) vengono conservati in memoria per massimo 10 minuti o fino al primo download.

Cookie

Questo sito usa solo cookie tecnici strettamente necessari al funzionamento (es. verifica Cloudflare Turnstile). Non usiamo cookie di tracciamento, profilazione o pubblicitari.

4. Ruolo nel trattamento dei dati

Per i file che carichi (che potrebbero contenere dati di fatture di aziende o professionisti), agiamo come responsabile del trattamento ai sensi dell'art. 28 GDPR:

  • Finalità: Sola conversione ed estrazione del file caricato
  • Durata: Il tempo strettamente necessario all'elaborazione (pochi secondi)
  • Istruzioni: Nessun uso proprio, nessuna conservazione, nessuna profilazione o analisi

Se sei un'azienda o professionista, tu rimani titolare del trattamento per i dati contenuti nei file che carichi.

7. Sicurezza

Adottiamo misure tecniche e organizzative per proteggere i dati:

  • Connessione HTTPS crittografata
  • File caricati elaborati solo in memoria, mai scritti su disco

  • Parser XML sicuro (senza entità esterne)
  • Limiti di dimensione file e profondità annidamento (anti zip-bomb)
