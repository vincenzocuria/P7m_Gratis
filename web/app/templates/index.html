Domande frequenti

Cosa sono i file .p7m?

I file .p7m sono documenti firmati digitalmente con standard CAdES/PKCS#7. Vengono usati dalla Pubblica Amministrazione e dalle aziende per fatture elettroniche, determine, contratti e altri documenti ufficiali.

I miei file vengono salvati?

No, mai. Tutti i file vengono elaborati in memoria sul server e cancellati immediatamente dopo l'invio della risposta. Non conserviamo alcun dato. Leggi la nostra informativa sulla privacy.

Posso convertire più file contemporaneamente?

Sì! Carica un file ZIP contenente fino a 20 file .p7m (limite gratuito). Per batch più grandi, ti consigliamo di usare l'app desktop P7M Viewer.
